# amuxify Homebrew tap

Homebrew cask for [amuxify](https://github.com/amuxify/amuxify), the ingest
gate for self-hosted media.

## Install

```sh
brew install --cask amuxify/tap/amuxify
amuxify doctor
```

The cask installs the release binary and pulls in `ffmpeg` and `mkvtoolnix`.

## Upgrade

```sh
brew upgrade --cask amuxify
```

## Uninstall

```sh
brew uninstall --cask amuxify
brew untap amuxify/tap
```

## How this repository is maintained

`Casks/amuxify.rb` is generated by goreleaser from the
[amuxify release pipeline](https://github.com/amuxify/amuxify/blob/main/.goreleaser.yaml)
on every tagged release. Do not edit it by hand; changes are overwritten by
the next release. Report problems in the
[amuxify issue tracker](https://github.com/amuxify/amuxify/issues).
